# 홈 화면 랜덤 스토리카드

`GET /api/v1/story-cards/featured?size=5`

로그인 없이 호출합니다. `size`는 기본 5, 허용 범위는 1~20이며 잘못된 값은 400입니다.
전체 스토리카드 중 요청마다 랜덤으로 조회합니다. 한 응답 내 중복은 없지만,
이전 요청과 같은 카드가 나올 수 있습니다. 데이터가 부족하면 존재하는 개수만,
없으면 빈 배열을 반환합니다. 별도 DB 마이그레이션은 필요하지 않습니다.

```json
{
  "code": 0,
  "message": "추천 스토리카드 조회에 성공했습니다.",
  "data": [
    {
      "storyId": 3,
      "spotId": 24,
      "tourSpotName": "동궁과 월지",
      "title": "달빛 이야기",
      "subTitle": "신라의 밤",
      "summary": "카드 요약",
      "imageUrl": "https://example.com/story.jpg"
    }
  ]
}
```

이 API는 홈 카드용 요약을 반환합니다. 상세 조회·저장·저장 취소·내 저장 목록의
기존 로그인 요구사항은 유지됩니다.
